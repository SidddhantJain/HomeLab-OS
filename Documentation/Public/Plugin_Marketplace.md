# Plugin Framework & Application Catalog Specification

## Plugin Framework
- Plugin metadata registration (`PluginMetadata`).
- Permission scoping (`READ`, `WRITE`, `EXECUTE`, `ADMIN`).
- Version compatibility checks against HomeLab OS core.

## Application Catalog
Pre-configured templates for 9 self-hosted Docker workloads:
1. **Immich** (Photos & Media)
2. **Jellyfin** (Media Server)
3. **Nextcloud** (Productivity Suite)
4. **Vaultwarden** (Password Manager)
5. **Gitea** (Git Service)
6. **Grafana** (Observability Dashboards)
7. **Prometheus** (Metrics Storage)
8. **Pi-hole** (Network Ad Blocking)
9. **Home Assistant** (Home Automation)
